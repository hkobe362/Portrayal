### Added
- `docs/rack-file-v4-design.md`, the design note for rack file version 4,
  decided 2026-10-11: one version, from one build, for every key held back
  so far. It gives the keys, types, defaults, fit sentences, exports and kit
  API for half-U positions (`ru` in steps of 0.5, #970), stock length and
  the record of slack (#949 step 4, with the stock break of #983), outlet
  states and readings (#934), PDU brackets (#939), `roll`, and breakout and
  anchor straps; says which rack products keys ride with them (#935); and
  that a device on a shelf DIN rail (#972) needs no key beyond `heldBy`. Its
  thirteen decisions are recorded with the options not taken and what is
  one-way. Spare cable is recorded and listed in version 4 and drawn later
  (#1011); tie points on rings (#1009) and the ear plan for a body under one
  unit (#1010) are follow-ups. Nothing is built: no schema, kit or library
  file changes.
