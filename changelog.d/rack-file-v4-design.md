### Added
- `docs/rack-file-v4-design.md`, the design note for rack file version 4: one
  version, from one build, for every key held back so far. It gives the keys,
  types, defaults, fit sentences, exports and kit API for half-U positions
  (`ru` in steps of 0.5, #970), stock length and the record of slack (#949 step 4, with the
  stock break of #983), outlet states and readings (#934), PDU brackets
  (#939) and `roll`, says which rack products keys ride with them (#935), and
  that a device on a shelf DIN rail (#972) needs no key beyond `heldBy`. It
  also covers breakout and anchor straps, lists thirteen decisions to take, and
  says what is one-way. Nothing is built: no
  schema, kit or library file changes.
